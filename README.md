<h1 align="center">Element Index Defaults for Craft CMS</h1>

Element Index Defaults is a Craft CMS plugin that puts the useful columns in Craft's element indexes before every editor has to configure them. Set a project-wide starting view for entries, assets, categories, users, and other element types.

Put the fields editors scan and compare most often on screen from the start, so nobody has to customise every content index before it's useful.

## Features

- Choose which attributes and custom fields appear when an index is first used.
- Show the editorial details teams use most in the entry index.
- Expose useful file and custom-field details in the asset index.
- Show more useful columns in the category index from the outset.
- Show the account details administrators refer to most often in the user index.
- Configure defaults for compatible element types registered by other plugins.
- Tailor defaults to the element type and source instead of imposing one global table.
