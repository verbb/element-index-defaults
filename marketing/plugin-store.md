Element Index Defaults puts the useful columns in Craft’s element indexes before every user has to configure them. Set a project-wide starting view for entries, assets, categories, users, and other element types.

Editors should not have to customise every content index before it becomes useful. Put the fields they scan and compare most often on screen from the start.

## Features

- **Default columns:** Choose which attributes and custom fields appear when an index is first used.
- **Entries:** Surface the editorial information that helps teams manage content.
- **Assets:** Expose useful file and custom-field details in the asset index.
- **Categories:** Give taxonomy managers a more informative list from the outset.
- **Users:** Present the account details administrators refer to most often.
- **Third-party elements:** Configure defaults for compatible element types registered by other plugins.
- **Per-source control:** Tailor defaults to the element type and source instead of imposing one global table.
- **Different content, different defaults:** Give entries, assets, categories and users the starting columns that make sense for the people managing them.
