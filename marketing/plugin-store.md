Element Index Defaults puts the useful columns in Craft's element indexes before every user has to configure them. Set a project-wide starting view for entries, assets, categories, users, and other element types.

Editors should not have to customise every content index before it becomes useful. Put the fields they scan and compare most often on screen from the start.

## Features

- Choose which attributes and custom fields appear when an index is first used.
- Surface the editorial information that helps teams manage content.
- Expose useful file and custom-field details in the asset index.
- Give taxonomy managers a more informative list from the outset.
- Present the account details administrators refer to most often.
- Configure defaults for compatible element types registered by other plugins.
- Tailor defaults to the element type and source instead of imposing one global table.
